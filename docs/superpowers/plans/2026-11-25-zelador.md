# Zelador do Catálogo — plano de implementação

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Criar o subagente "zelador", que faz uma ronda de 8 passos no site publicado pelo Chrome e devolve um relatório ✅/⚠️/❌ sem alterar nada.

**Architecture:** Um único arquivo de definição de subagente do Claude Code (`.claude/agents/zelador.md`): cabeçalho com nome, descrição e lista fechada de ferramentas (só Claude in Chrome), seguido do "manual" em português. O "teste" é uma ronda real que o dono assiste ao vivo.

**Tech Stack:** Subagentes do Claude Code, ferramentas MCP `mcp__claude-in-chrome__*`.

**Spec:** [docs/superpowers/specs/2026-11-25-zelador-design.md](../specs/2026-11-25-zelador-design.md)

## Global Constraints

- Site alvo: `https://catalogo-streaming-one.vercel.app` (nunca localhost, nunca outro domínio).
- Ferramentas permitidas: somente `mcp__claude-in-chrome__*` listadas na Task 1. Nada de Bash, PowerShell, Read, Edit, Write, Agent.
- Proibido: entrar na conta, clicar em "excluir conta"/"baixar dados"/"Sair", qualquer ação que altere dados, disparar alert/confirm do navegador.
- Trabalha numa aba nova e fecha essa aba ao final; não toca nas abas do dono.
- Relatório em português, uma linha por item da ronda, terminando com "Resumo: N problemas, N alertas. Nada foi alterado."
- Antes de marcar ❌, tenta de novo uma vez (recarregar) e descreve o que viu.
- Nunca afirmar que conferiu algo que não conferiu; se não conseguiu conferir, marca ⚠️ "não consegui conferir" e diz por quê.

## Review Focus

1. Chrome sem a extensão conectada → o Zelador deve parar e relatar "Chrome não conectado", não inventar resultados.
2. Site lento (TMDB demorando) → esperar alguns segundos antes de concluir que algo não carregou.
3. Pôsteres com carregamento preguiçoso (lazy) → conferir imagens quebradas só entre as que já carregaram, sem confundir "ainda não carregou" com "quebrada".
4. Página de filme com link "Assistir" para o streaming → não clicar (sai do site).
5. Busca sem resultado com selo → registrar ⚠️ com o que apareceu, não ❌, se a página em si funciona.

Os itens 1–5 viram instruções explícitas no manual (Task 1) e são conferidos na ronda real (Task 2).
